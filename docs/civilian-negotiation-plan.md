# Autonomous civilian negotiation plan

Baseline ae5dbb2, feature/logistics-ingestion isolated worktree. User explicitly requests implementation and chose deterministic agent policies. Existing autonomous workflow authorization and civilian fictional scope persist. No military/combat functions, model-led choices, external tools or irreversible actions.

## Design and public contract
Implement real bounded contract-net negotiation before optimization, not a posthoc transcript. Cargo initiates proposals for civilian requests (priority descending, stable ID tie), independently evaluated by fleet/crew/weather/airport/cargo agents. Agents have inbox/outbox state, local constraint policies and role-specific candidate preferences. Messages are typed, revision-scoped and delivered to all other peers plus supervisor. On objections, independently computed local bid lists are broadcast; peers propose alternatives from the advertised joint intersection and cargo selects among counterproposals. Accepted proposals reserve resources for subsequent requests. Supervisor requires all five acceptances before committing an incumbent. Hard constraints may never be bargained away.

Every revision executes fresh negotiation (start/scripted step/gateway batch/input expiry/weather), synchronously inside existing atomic persistence; no network/model calls. Runtime budgets maxRounds1..8 default4 per request, maxMessages32..512 default512. Budget exhaustion returns a verified feasible partial seed and explicit status. Finite candidate universe at most135 raw tuples; no unbounded loop. Empty/infeasible scenarios have explicit no-agreement outcomes. Agent policy faults produce explicit failed negotiation + deterministic unseeded optimization fallback; no fabricated consensus.

Existing exact optimizer retains objective/tie rules, uses independently checked seed as incumbent, and may refine it. Valid seeded budget-limited plans outperform empty search incumbents; completed search returns same optimum as unseeded search. Existing checker remains authoritative. Reports, projections, outbox, TTL, auth and optional local LLM annotation behavior remain intact.

Start schema adds optional `negotiation:{enabled?:boolean,maxRounds?:int1..8,maxMessages?:int32..512}` with strict object and server defaults. New runs default enabled; disabled leaves existing deterministic supervisor evidence. Persist chosen settings in negotiation report; later revisions carry them forward. Legacy snapshots without report migrate lazily on next revision using enabled defaults.

Snapshot `negotiation`:
`{version:1,runId,revision,mode:'deterministic-autonomous',topology:'fully-connected-peers',settings:{enabled,maxRounds,maxMessages},previousAssignments:[canonical tuples],status:'agreed'|'partial'|'no_agreement'|'budget_exhausted'|'failed'|'disabled',roundsCompleted,requests:[{requestId,status:'agreed'|'blocked'|'deferred'|'budget_exhausted',rounds,assignment?}],agentStates:[{agentId,acceptedProposalIds,rejectedProposalIds,bidsSent}],messages:[{id,round,requestId?,proposalId?,from,to,kind,entityIds,findingIds,ruleCodes,summary,candidateId?,candidateIds?,assignment?}],assignments:[canonical tuples],outcome:{status:'seed-retained'|'solver-refined'|'deterministic-fallback'|'disabled',seedServedPriority,finalServedPriority,verified}}`.

Message kinds cfp/proposal/accept/reject/bid/counterproposal/commit/defer/resolution. IDs deterministically include full run UUID/revision/sequence; all optional assignment/IDs refer to current scenario/candidate universe. from/to limited five peers/supervisor, no arbitrary receiver/tools. Finding IDs refer only to canonical report evidence; assignment-specific ruleCodes are deterministic checks, distinct from canonical finding codes. Transcript budget includes decision messages; fail before partial message delivery; commit must follow complete unanimous accepted votes. No consensus claims on partial votes or missing budget. Outcome honestly distinguishes negotiated incumbent from optimizer final assignments. A compact final resolution may be represented in outcome if trace capacity is exhausted; never exceed configured maxMessages.

## Required invariants
No negotiation action assigns invalid tuple, duplicates resources, changes request priority/objective, relaxes weather/duty/capacity rules or mutates input. Transcript is generated by executed routing; votes and bid intersection actively decide accepted seed. Replanning starts with empty reservations and new revision message IDs; previous incumbents only preferences. Bounded budgets produce explicit incomplete status, partial votes never commit, retained seed independently checked. Agent exceptions cannot silently masquerade as agreement. No regression in exact replay, expiry historical labeling or source/admin/viewer separation.

Review ruling: deterministic transcript replay plus independent local-vote/quorum/seed checks rejects fabricated metadata, omitted peer deliveries and missing bid/counter causality. Reports retain at most five prior assignments to make that policy context self-contained; runtime validates against its actual prior plan. Viewer correlates known proposal/request/round/candidate references, rather than testing membership alone.
